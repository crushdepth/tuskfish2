sRGB-v2-magic.icc

Compact sRGB colour profile used by the optional ImageMagick thumbnail trait
(class/Tfish/Traits/ResizeImage-Imagick.php) to convert JPEG thumbnails to sRGB.

Source:  https://github.com/saucecontrol/Compact-ICC-Profiles (profiles/sRGB-v2-magic.icc)
Licence: Creative Commons CC0 1.0 Universal (public domain dedication), see LICENSE-CC0.txt.

The file is unmodified. To use a different sRGB profile, change $profilePath in
createThumbnailWithExec().
